
# Управление моделью машинки по Bluetooth (STM32)

## Описание проекта
Разработка системы управления игрушечной машинкой / роботом с помощью Bluetooth (модуль HC-05). Проект нацелен на понимание работы периферии микроконтроллера STM32: настройка таймеров для генерации ШИМ-сигнала (управление скоростью двигателей), работа с UART (прием команд с телефона) и управление GPIO.

**Ключевые особенности:**
*   Управление через стандартный Bluetooth-модуль (AT-команды).
*   Плавное регулирование скорости двигателей с помощью ШИМ (PWM).
*   Написана на чистом C с использованием стандартной периферийной библиотеки HAL.

## Аппаратное обеспечение
*   Микроконтроллер: STM32
*   Bluetooth-модуль: HC-05
*   Драйвер моторов: L298N

## Программное обеспечение 
*   **Среда разработки:** STM32CubeIDE и Keil uVision
*   **Язык:** C
*   **Используемые библиотеки:**
    *   HAL — для работы с периферией.

## Установка и настройка 

### Требования
*   Установленная среда разработки.
*   Утилита для отправки команд по Bluetooth с телефона (например, "Bluetooth Terminal" или "Serial Bluetooth Terminal").

# Использование 
*   Подайте питание на схему.

*   Подключитесь с телефона к Bluetooth-модулю (пароль по умолчанию 1234 или 0000).

*   Откройте терминальное приложение на телефоне.

*   Отправляйте команды:

    *   F - Вперед

    *   B - Назад

    *  L - Влево

    *  R - Вправо
      
    *  0-9 - Изменить скорость

#  Текущий статус
